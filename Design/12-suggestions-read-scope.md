# 12 — Suggestion (Tool · Guide · Inline) · ขอบเขตการอ่านของ AI (ภาพรวม / Secured / Opened)

> ร่าง v0.4 · 2026-11-02 · เจ้าของสั่ง: เพิ่มระบบ **Tool Suggestion / Guide Suggestion** ที่แนะนำจากสิ่งที่ผู้ใช้กำลังทำ
> (แรงบันดาลใจ: Quick Analysis/Ideas ของ Excel + inline suggestion ของ Copilot) · อยู่ใน plugin ของแต่ละแอป Eco และ**มากับแอปตอนติดตั้ง** ·
> ฉลาดขึ้นเมื่อมีโมเดลที่โหลดใน Z.I.Z · ฉลาดขึ้นอีกเมื่อเปิดใช้ CLI ของผู้ใช้ (**เปิดเองในหน้า Node เท่านั้น** เพราะกินโทเคนจริง) ·
> และเพิ่ม**ขอบเขตการอ่าน**ลดโทเคน/hallucination ของ DraconDex (และแอปอื่นภายหลัง)
> ต่อจาก `08` (โมเดล) · `10` §2 (Home = หน้า Node) · `10` §4 (Spaces) · `11` (Link) · ❓ ใหม่อยู่ `07-grill-me.md` รอบ 10

## 1. Suggestion คืออะไร — 3 รูปแบบ

| รูปแบบ | หน้าตา | ได้แรงจาก | ตัวอย่าง |
|---|---|---|---|
| **S-tool** (Tool Suggestion) | ปุ่ม `✦` เล็ก ๆ ข้างสิ่งที่เลือก → เปิดเมนูเครื่องมือที่เข้ากับสิ่งนั้น 1–4 อย่าง | Excel Quick Analysis | เลือกตัวละคร 5 ตัวใน BahaMyth → `✦ สร้างแผนผังความสัมพันธ์ · เทียบกับ RyuLong · ใส่แท็กเผ่าทีละหลายตัว` |
| **S-inline** (Inline Suggestion) | **ข้อความจาง (ghost)** ในช่องที่กำลังพิมพ์ · `Tab` = รับ · `Esc` = ทิ้ง · `Alt+]` = ตัวเลือกถัดไป | Copilot inline | พิมพ์ช่อง "เผ่า" ของตัวละครใหม่ → ghost `มนุษย์` (ตัวละครที่สร้างคู่กันมักเป็นเผ่านี้) · พิมพ์ชื่อใน RyuLong `อา…` → ghost `ริน` |
| **S-guide** (Guide Suggestion) | การ์ดในแผง Link: "ถัดไปคุณมักจะ…" / "ยังขาด…" + ปุ่มหลักปุ่มเดียว | Excel Ideas + Spaces (`10` §4) | สร้างตัวละครเสร็จ → `✦ ปกติคุณจะใส่รูปและลิงก์สถานที่ต่อ (4 ครั้งที่แล้ว) [ทำต่อ]` |

**หลักที่ไม่เปลี่ยน** (ต่อ `05` หลัก 6 ข้อ):
1. **ไม่ทำเองอัตโนมัติ** — ทุก suggestion ต้องกดรับ · การรับ S-inline/S-tool ภายในแอปเดียว = การกระทำปกติของผู้ใช้ในแอปนั้น (เหมือนพิมพ์เอง · undo ของแอปเอง) ·
   suggestion ที่เขียน**ข้ามแอป**หรือหลายรายการ → ไป **Mirror** (`10` §3) เสมอ
2. **บอกที่มาทุกครั้ง** — ป้ายชั้น `S0 กฎ` · `S1 โมเดล` · `S2 Claude Code` (§2) + เหตุผลบรรทัดเดียว ("เพราะ 4 ครั้งก่อนคุณทำแบบนี้")
3. **เงียบเป็นค่าเริ่ม** — ไม่มี popup · ghost ไม่บังข้อความ · แสดงเฉพาะเมื่อความมั่นใจถึงเกณฑ์ (§3.3) · ทิ้ง 3 ครั้งติด = หยุดแนะนำแบบนั้นในช่องนั้น 7 วัน

## 2. สามชั้นของความฉลาด

```
            ทำงานได้เมื่อ…                         ใช้อะไร                              ค่าใช้จ่ายของผู้ใช้
S0 ฐาน     ติดตั้งแอป Eco แล้ว (ไม่ต้องมี Z.I.Z)     กฎตายตัว + ตารางนับ habit ในแอป        0 (CPU เล็กน้อย)
S1 โมเดล   + มี Z.I.Z และโหลดโมเดลแล้ว (`08`)       embed · ner · habit · route · gen*     0 (ในเครื่อง)
S2 CLI     + ผู้ใช้เปิดเองในหน้า Node ของ Z.I.Z     CLI agent ของผู้ใช้ (`02` §3)           โทเคน/โควตาจริงของผู้ใช้
```
ชั้นสูงกว่า**เติม**ชั้นล่าง ไม่แทน · ชั้นไหนไม่พร้อม (Z.I.Z ปิด / โมเดลยังไม่โหลด / CLI ไม่ login) → ตกลงชั้นล่างเงียบ ๆ พร้อมจุดสถานะในแผง Link

### 2.1 S0 — มากับแอปตอนติดตั้ง (`ziz-suggest-core`)

- **เปลี่ยนจาก `11` §2:** Link (ถาม/ค้น/สรุป) ยังติดตั้งอัตโนมัติเมื่อมีทั้งสองฝั่งเหมือนเดิม แต่ **S0 ไม่ต้องรอ Z.I.Z** —
  เป็น plugin ในตัว (built-in) ที่ installer ของแต่ละแอปวางลงโฟลเดอร์ plugin ของตัวเอง ผ่าน plugin host `zydraxyl-ext/1` (P14) · ปิดได้ใน ตั้งค่า → Extensions
- เหตุผลที่มากับแอปได้ (ต่างจาก Link): **ไม่มี AI · ไม่มีเน็ต · ไม่อ่านข้อมูลข้ามแอป · ไม่ส่งอะไรออกจากแอป** — เป็นแค่ "กฎของแอปเอง" ที่ใช้ UI ร่วม
- โครง — **repo แยก `ZIZ-SUGGEST`** (รอบ release ตาม build ของแอปเจ้าบ้าน ไม่ใช่ catalog แบบ Link — `02` §6.1):
  ```
  ZIZ-SUGGEST/
    core/          engine + UI ghost/chip/card (vanilla JS · tokens.css ของ Eco) — ชุดเดียวทุกแอป
    rules/<app>/   rules.json ต่อแอป (ตรวจด้วย schema `suggest-rules/1` จาก `ZIZ-PROTOCOLS`) — ❓ Q60
  ```
  แอปเจ้าบ้าน vendor `ZIZ-SUGGEST` ด้วย tag ตอน build installer · อัปเดต S0 = ออกเวอร์ชันแอปนั้นใหม่
- กฎตัวอย่าง (`rules.json` — ประกาศ ไม่ใช่โค้ด):
  ```json
  { "id": "baha.char.no-link", "on": "entity.saved", "when": { "kind": "character", "links": 0 },
    "show": "guide", "text": "ยังไม่มีความสัมพันธ์ — เพิ่มเลยไหม", "action": "baha:link.add" }
  { "id": "baha.char.race", "on": "field.typing", "field": "race",
    "show": "inline", "from": "habit.mostCommon(project, kind=character, field=race)" }
  ```
- habit ของ S0 = **ตารางนับ** ในแอป (ค่าที่ใช้บ่อยต่อช่อง · คู่ action ที่ตามกันบ่อย) จาก event ในแอปเอง —
  ponytail: นับความถี่ + คู่ลำดับ (bigram) เท่านั้น · ลำดับยาว 2–6 และ Markov อันดับ 2 เป็นงานของ `ZIZ-M-habit` ใน S1 (`10` §4.3)
- ไม่มี Z.I.Z ในเครื่อง → S0 ยังทำงานครบ · มีบรรทัดเล็กท้ายแผง: "ติดตั้ง Z.I.Z เพื่อคำแนะนำข้ามแอป" (แสดงครั้งเดียวต่อสัปดาห์ ปิดได้)

### 2.2 S1 — เมื่อมี Z.I.Z + โมเดลที่โหลดแล้ว

S0 ถาม Z.I.Z ผ่าน pipe ของ Link (`11` §3.2) ด้วย method ใหม่ `link_suggest` (§5) · Z.I.Z ตอบด้วยผู้สมัครที่ฉลาดกว่า:

| โมเดล (`08` §2) | เพิ่มอะไรให้ suggestion |
|---|---|
| `ZIZ-M-habit` | ลำดับยาว + "ถัดไปคุณมักจะ" ข้ามแอป (BahaMyth → RyuLong) · S-guide |
| `ZIZ-M-embed` | S-inline ของชื่อ/alias ที่มีในต้นฉบับ · S-tool "มีตัวละครคล้ายกันอยู่แล้ว 2 ตัว" |
| `ZIZ-M-ner` | ชื่อในต้นฉบับที่ยังไม่มี entity → S-guide "สร้าง 6 ตัวละครที่ยังขาด" (→ Mirror) |
| `ZIZ-M-route` | คัดข้อความที่ highlight ว่าเป็นคำสั่งแฝงไหม ก่อนใช้เป็นบริบท (`04` §7.2) |
| `ZIZ-M-gen` (opt-in) | S-inline ประโยคสั้น (เช่น ช่องคำอธิบาย ≤ 1 ประโยค) · ติดป้าย `S1 gen` เสมอ |

- งบ: `link_suggest` ตอบ **< 80 ms** (S-inline) / **< 300 ms** (S-tool, S-guide) · เกินงบ = ไม่แสดง (ไม่ค้าง ไม่รอ)
- ทุกผลมี ref ที่มาใน index (หลัก "หลักฐานก่อนความเชื่อ") · ไม่มีที่มา = ไม่แสดง

### 2.3 S2 — CLI ของผู้ใช้ (เปิดเองในหน้า Node เท่านั้น)

- **ปิดเป็นค่าเริ่มและเปิดได้ที่เดียว:** หน้า Node (Home `10` §2) → คลิกโหนดแอป → แผงขวา → `AI ช่วยแนะนำ (ใช้ Claude Code)` ·
  เปิด **ต่อแอป ต่อโปรเจกต์** · ไม่มีทางเปิดจากในแอปเจ้าบ้าน (Link แสดงแค่สถานะ `S2 ปิด — เปิดได้ใน Z.I.Z`) เพื่อไม่ให้กดพลาดแล้วเสียโทเคน
- ตอนเปิดแสดง: ประมาณโทเคนต่อครั้ง/ต่อวันจากขนาดบริบท (§4.4) · เพดานต่อวัน (ค่าเริ่ม **20 คำขอ หรือ 60k โทเคน** ต่อโปรเจกต์ แล้วหยุดเอง) · ขอบเขตการอ่านที่จะใช้ (§3)
- **ไม่ยิงตอนพิมพ์** — S2 ไม่ทำ S-inline (ช้าและแพงเกิน) · ทำเฉพาะ:
  - S-guide/S-tool เมื่อผู้ใช้ **หยุดนิ่ง ≥ 20 วินาที** หลังบันทึก หรือกด `✦ แนะนำลึก` เอง
  - ส่งเฉพาะ **LinkContext + สรุปจาก S1** (ไม่ส่งเนื้อหาไฟล์เต็ม) · agent อ่านเพิ่มได้ผ่าน gateway **ภายในขอบเขต §3** เท่านั้น
- ผลของ S2 = ข้อเสนอ (changeset ร่าง) → Mirror เสมอ · ไม่เคยเป็น ghost ที่กด Tab รับได้
- แถบสถานะของ Z.I.Z แสดง `S2 ● 7/20 วันนี้ · ~18k โทเคน` · ปิดทันทีได้จากแถบนี้

## 3. ขอบเขตการอ่านของ AI — ภาพรวม / Secured / Opened

ใช้กับ **ทุกทางที่ AI อ่านข้อมูลโปรเจกต์**: agent ในแชต (`02` §3) · Link `link_ask` · S2 · Terminal โหมดต่อกับโปรเจกต์ (`11` §6.2) ·
agent ที่ต่อแอปตรงแบบอ่านอย่างเดียว (`02` §4.3, P17) · และ **AI ของ DraconDex ภายใน Nexus** (เสนอให้ใช้ชุดเดียวกัน — P20) แล้วแอปอื่นตามมาภายหลัง

### 3.1 สามระดับ

| ระดับ | Z.I.Z อ่านอะไร | AI อ่านอะไร | ใช้เมื่อ |
|---|---|---|---|
| **◇ ภาพรวม** (ค่าเริ่ม) | เปิดไฟล์อ่าน **ค่าเริ่มต้นเท่านั้น**: relation · status · kind · จำนวน · วันที่แก้ (จาก `eco_stats`/รูปแบบสาธารณะ P18) → แสดงบนหน้า Node | **ไม่ได้อะไรเลย** — ไม่มีเนื้อหาเข้า agent/โมเดล gen · S2 ใช้ไม่ได้ | เปิดโปรเจกต์ดูสถานะ · ยังไม่ได้สั่งงาน AI |
| **🔒 Secured** | เหมือนภาพรวม + เนื้อหาในโฟลเดอร์ที่เลือก | **เฉพาะโฟลเดอร์ที่เลือก** (1 ขึ้นไป) ใน Nexus/โปรเจกต์ · นอกนั้น**ต้องถามก่อน** (§3.3) | งานเจาะจง · ประหยัดโทเคน · ลด hallucination |
| **🔓 Opened** | ทั้ง Nexus/โปรเจกต์ที่เปิด | ทั้ง Nexus/โปรเจกต์ที่เปิด — **แต่ไม่ข้ามไปโปรเจกต์อื่น** | งานภาพรวม/ข้ามบท ที่ต้องเห็นทั้งหมด |

- ระดับตั้ง **ต่อโปรเจกต์** และ **job/แท็บ terminal/การเปิด S2 แต่ละครั้งพกระดับของตัวเอง** (ค่าเริ่ม = ของโปรเจกต์) · เปลี่ยนระหว่างงาน → มีผลกับคำขอถัดไป ไม่ย้อนผลที่อ่านไปแล้ว
- ภาพรวม → เริ่มงาน AI ครั้งแรก: Z.I.Z ถามสั้น ๆ `ให้ AI อ่าน: [เลือกโฟลเดอร์ (Secured)] [ทั้งโปรเจกต์ (Opened)] [ยกเลิก]` · ปุ่ม focus = Secured
- "ภาพรวม" ของ Z.I.Z อ่านค่าเพื่อแสดงผลเท่านั้น — **ไม่ได้ส่งเข้า index ความหมาย (embed) จนกว่าจะเป็น Secured/Opened** (ponytail: BM25 ชื่อไฟล์/หัวเรื่องยัง index ได้ เพราะไม่มีเนื้อหา)

### 3.2 บังคับที่ไหน — ที่ gateway ไม่ใช่ใน prompt

prompt บอก agent ได้ แต่ **ไม่ใช่ตัวกั้น** · ตัวกั้นจริงอยู่ในโค้ดที่ agent ผ่านเสมอ:

| จุด | บังคับอย่างไร |
|---|---|
| token ของ gateway (`02` §4.1) | ผูก **session + workspace + job + scope** · `scope = { level, roots: ["chapters/arc-2", …] }` |
| `ziz_source_read` · `ziz_index_search` · `ziz_app_get` · `ziz_candidates` | ref/ไฟล์ที่อยู่นอก `roots` → **ไม่คืนเนื้อหา** คืน `{ "outOfScope": true, "path": "…", "hint": "ใช้ ziz_scope_request" }` · ผลค้นถูกกรองตาม prefix **ก่อน** จัดอันดับ (ไม่หลุดแม้ใน snippet) |
| `ziz-index` | filter `root-prefix` ใน query (`09` §1) — ใช้ตัวเดียวกับ `@ขอบเขต` ของ palette |
| แอปต่อตรงแบบอ่านอย่างเดียว | `<app>.exe --mcp --read-only --project <uid> --scope <roots>` (ขยาย P17 → P20) · แอปที่ไม่รองรับ `--scope` = **ไม่ให้ต่อตรงในโหมด Secured** ใช้ gateway แทน |
| Terminal ต่อกับโปรเจกต์ | `ziz-readonly.json` ที่สร้างต่อแท็บพก scope · ป้ายบนแท็บ `◆ Moonfall · 🔒 chapters/arc-2` · (shell ในแท็บยังเต็มสิทธิ์ของผู้ใช้ — `11` §6.3 · scope คุมเฉพาะ tool ของ Z.I.Z) |
| `ziz_terminal_log` | อ่านเฉพาะแท็บที่ scope ไม่กว้างกว่าของ job |

### 3.3 อ่านนอกขอบเขต → ถามก่อน (Secured)

```
agent เรียก ziz_scope_request(path, reason)        ← tool ใหม่ · อ่านอย่างเดียว · ไม่คืนเนื้อหา
  → Z.I.Z แสดงกล่อง (Z24):
    ┌ Claude Code ขออ่านนอกขอบเขต ────────────────────────────────┐
    │ โฟลเดอร์: lore/races   (12 ไฟล์ · ~9k โทเคน)                 │
    │ เหตุผล (จาก agent — ข้อมูล ไม่ใช่คำสั่ง): "ต้องเช็กเผ่าของอาริน"   │
    │ [อนุญาตครั้งนี้] [อนุญาตจนจบงาน] [ปฏิเสธ]                       │
    └──────────────────────────────────────────────────────────────┘
  → อนุญาต: เพิ่ม path เข้า roots ของ job นี้ (ไม่แก้ค่าของโปรเจกต์) · บันทึกใน runs/*.ndjson
  → ปฏิเสธ: agent ได้ "ปฏิเสธ — ตอบจากขอบเขตเดิมเท่านั้น"
```
- ปุ่ม focus = **ปฏิเสธ** (เหมือน Z8 `05`) · ขอซ้ำ path เดิมในงานเดียวกันหลังถูกปฏิเสธ = ปฏิเสธอัตโนมัติ (กันกล่องรัว)
- เหตุผลของ agent แสดงแบบข้อความล้วน ติดป้าย "ข้อมูล ไม่ใช่คำสั่ง" — ข้อความใน path/เหตุผลอาจมาจาก injection (`04` §7)
- S2 และ Link `link_ask`: ไม่มีกล่องกลางงาน → คำขอนอกขอบเขตถูกเก็บเป็นการ์ด `ขออ่านเพิ่ม 1 โฟลเดอร์` ให้ผู้ใช้กดทีหลัง

### 3.4 ลดโทเคน + ลด hallucination ได้อย่างไร

| กลไก | ผล |
|---|---|
| **อ่านภาพรวมก่อนเนื้อหา** — งานทุกงานเริ่มด้วย `ziz_scope_outline()` (tool ใหม่): ต้นไม้ของ roots + relation/status/จำนวน ≤ 2k โทเคน | agent รู้ว่ามีอะไรโดยไม่ต้องเปิดไฟล์ทีละไฟล์ |
| ขอบเขตแคบ = ผลค้นน้อยลง | ตัวอักษรที่ส่งให้ agent ลดลงตามสัดส่วนโฟลเดอร์ (เป้า: Secured 1 โฟลเดอร์ ≤ 30 % ของ Opened ใน fixture `novel-*`) |
| **"ไม่พบในขอบเขต" เป็นคำตอบที่ถูกต้อง** — system prompt ของ recipe + ผลของ tool บอกชัดว่าไม่พบ | agent ไม่เดาจากความรู้ทั่วไป · Link/S2 แสดง "ไม่พบใน chapters/arc-2 · [ขยายขอบเขต]" |
| ทุกข้อเท็จจริงต้องมี quote + ref ในขอบเขต — ตรวจ quote (`04` §5.7) ปฏิเสธ quote ที่มาจากนอก roots | คำตอบที่อ้างสิ่งที่ agent ไม่ได้อ่านถูกตัดทิ้ง |
| งบต่อคำขอ (`ziz_source_read` ≤ งบตัวอักษร `04` §5.4) + cache IR (`09` §4) | ไม่อ่านไฟล์เดิมซ้ำ |

### 3.5 กับ DraconDex (และแอปอื่นภายหลัง)

- DraconDex มี AI/agent ที่อ่าน Nexus เอง → เสนอให้ใช้ **สัญญาขอบเขตชุดเดียวกัน** (`scope = { level, roots }` + `outOfScope` + `scope_request`) เป็น P20 ·
  Z.I.Z ไม่เขียนโค้ดลง DraconDex — ให้ spec + ชุดทดสอบ (`ZIZ-PROTOCOLS/scope/`) · DraconDex ทำก่อน (Nexus = หน่วยเดียวกับ "โปรเจกต์" ในตารางข้างบน) แล้วแอปอื่นตาม
- ก่อน DraconDex รองรับ: Z.I.Z บังคับได้เฉพาะทางที่ผ่าน gateway ของ Z.I.Z เท่านั้น — หน้า Node แสดงป้าย `DraconDex AI: ยังไม่รองรับขอบเขต` (ไม่ซ่อน)

- มุมมองรายการ ☰ (`10` §2.4) มีคอลัมน์ `AI อ่านได้` (ใช่/ไม่) — ไม่พึ่งความจางของสีอย่างเดียว

## 5. Protocol ที่เพิ่ม

**`link/1` → `link/1.1`** (MINOR — Link รุ่นเก่ายังคุยได้ · `11` §2.5):

| method | ทำอะไร | งบ |
|---|---|---|
| `link_suggest(ctx, kinds[], budgetMs)` | ผู้สมัคร suggestion ชั้น S1 (และ S2 ที่ค้างอยู่) สำหรับ LinkContext นี้ · คืน `[{ kind, text, action?, refs[], tier, confidence, why }]` | ตาม `budgetMs` (≤ 300) |
| `link_suggest_feedback(id, "accept" \| "dismiss" \| "never")` | ให้ habit เรียนรู้ (เก็บในเครื่อง · `via:"user"`) | — |
| `link_scope()` | ระดับ + roots ปัจจุบันของโปรเจกต์ (แสดงในแผง Link · **เปลี่ยนจาก Link ไม่ได้**) | — |

`ctx` ของ S-inline เพิ่ม `field` + `prefix` (≤ 200 ตัวอักษรก่อน cursor) · **ไม่ส่งทั้งเอกสาร** · ส่งเฉพาะช่องที่ `rules.json` ประกาศว่าแนะนำได้ (ช่องรหัสผ่าน/โน้ตส่วนตัวไม่มีทางถูกส่ง)

**gateway `zydraxyl-ziz`** (`02` §4.1) เพิ่ม — อ่านอย่างเดียวทั้งหมด:

| tool | ทำอะไร |
|---|---|
| `ziz_scope_outline()` | ต้นไม้ของ roots + ค่าภาพรวม (relation/status/จำนวน) ≤ 2k โทเคน |
| `ziz_scope_request(path, reason)` | ขอขยายขอบเขต (§3.3) · คืน `granted` / `denied` / `queued` · ไม่คืนเนื้อหา |
| `ziz_suggest_submit(items[])` | S2 ส่งคำแนะนำกลับ (ข้อความ + refs + ops ร่าง) → ผ่านตรวจ quote → การ์ด/ Mirror |
