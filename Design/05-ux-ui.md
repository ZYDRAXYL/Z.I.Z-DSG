## 1. หลักการ 6 ข้อ

1. **สามคำเท่านั้น:** แหล่ง → ข้อเสนอ → การเขียน · คำกริยา "เสนอ" กับ "เขียน/นำไปใช้" ห้ามสลับกัน
2. **ปุ่มเขียนมีที่เดียว** — ท้ายแผงข้อเสนอ ("นำไปใช้ N รายการ") · ไม่มีปุ่มเขียนในแชต
3. **หลักฐานก่อนความเชื่อ** — ทุกข้อเสนอมี quote + กระโดดไปต้นฉบับ · ความมั่นใจเป็นจุด + ตัวเลข
4. **ย้อนได้ดีกว่าถามซ้ำ** — กล่องยืนยันแบบบล็อกใช้เฉพาะสิ่งที่ย้อนไม่ได้หรือเสี่ยงสูง (UX-LAYOUT §8 ข้อ 10)
5. **ซื่อตรงเรื่องงานยาว** — บอกขั้น + เวลาที่ผ่าน + บทที่อ่านแล้ว · ไม่รู้ % = แถบไม่ระบุค่า · ยกเลิกได้เสมอและไม่มีอะไรถูกเขียน
6. **บอกเสมอว่าใครทำ** — ชิป agent บนแถบหัว · สถานะการเชื่อมต่อของแต่ละแอปบนแถบสถานะ

## 4. Flow ทีละขั้น

### 4.1 เริ่มครั้งแรก (≤ 3 ขั้น ข้ามได้)

1. **agent**: Z.I.Z หา CLI (`02-architecture.md` §3.3) → รายการ ✓ เวอร์ชัน / "ไม่พบ" + "วิธีติดตั้ง ↗" + "ระบุ path เอง…" →
   "ทดสอบการเชื่อมต่อ" → "พร้อม · 1.2 วินาที" หรือข้อผิดพลาดพร้อมวิธีแก้หนึ่งอย่าง ·
   **ไม่พบเลย** → ปุ่ม "ใช้ต่อโดยไม่มี agent" (โหมดไม่มี AI — ❓ Q1) ไม่บล็อก
2. **โปรเจกต์**: มี locator ของ Hub → "เลือกโปรเจกต์ Eco" (รายการจาก locator) · ไม่มี → "เปิดโฟลเดอร์…"
3. **ความเป็นส่วนตัว** (ครั้งแรกที่จะส่งข้อมูลโปรเจกต์นี้ให้ agent — ECO-S5): "ข้อมูลจะถูกส่งให้ Claude Code และผู้ให้บริการโมเดลของมัน
   Z.I.Z ไม่ส่งไปที่อื่น" → [อนุญาตสำหรับโปรเจกต์นี้] [ยังไม่อนุญาต]
4. ลงที่ Console พร้อมการ์ด recipe 3 ใบที่เหมาะกับแอปในโปรเจกต์ (empty state เป็นครู)

### 4.2 นิยาย → BahaMyth (เส้นทางหลัก)

1. ลาก `ch1-12.docx` ลง Console หรือวางข้อความ ≥ 2 KB → กลายเป็นชิปไฟล์แนบ → Z4 เปิด
2. Z4: ตรวจการแบ่งบท · เลือก recipe "นิยาย → BahaMyth" · ปลายทาง BahaMyth › Moonfall · ดูขนาด/เวลา → "วิเคราะห์"

## 8. Accessibility (WCAG 2.2 AA ตาม DraconDex)

- คีย์บอร์ดครบ: `Ctrl+P` palette · ในแผงข้อเสนอ `J/K` เลื่อน · `Space` ติ๊ก · `A` ยอมรับที่มองเห็น · `S` ข้าม · `Enter` เปิด diff · `Ctrl+Enter` นำไปใช้
- กล่องขอสิทธิ์: focus เริ่มที่ปุ่มปลอดภัย · Esc = ปฏิเสธ · ไม่มีกับดัก focus
- ข้อความที่ agent สตรีม: `aria-live="polite"` แบบหน่วง (อัปเดตทุก ~1 วินาที ไม่ใช่ทุก token)
- รายการ checkbox มีหัวกลุ่ม · ตาราง diff มีคำ "เพิ่ม/ลบ/แก้" ไม่ใช่สีอย่างเดียว · ความมั่นใจ = จุด + ตัวเลข
- รองรับ `prefers-reduced-motion`, Windows High Contrast (`forced-colors`), ขยายตัวอักษร 150 %, เป้าคลิก ≥ 24 px

## 9. ตัวอักษรไทย (T4-A D3)

- font stack: `"Segoe UI Variable Text","Segoe UI","Noto Sans Thai UI","Noto Sans Thai",system-ui,sans-serif` (ฟอนต์ร่วม ECO-T4)
- line-height ≥ 1.5 สำหรับเนื้อความ (สำคัญมากใน Z.I.Z เพราะแสดงข้อความนิยาย/quote เยอะ) · แถว 28 px ใช้ `line-height:1` + padding และทดสอบวรรณยุกต์ซ้อน
- เนื้อหาไทยยาว (quote, พรีวิวต้นฉบับ): 14 px (`fs-lg`) · chrome 13 px
- quote และพรีวิวต้นฉบับใช้ `lang="th"` ให้ browser ตัดบรรทัดตามคำ · path/ชื่อไฟล์ใช้ `overflow-wrap:anywhere` · ไม่ตัด `…` กลางคำไทย
- วันที่: พุทธศักราชหรือคริสต์ศักราชตามการตั้งค่า (ค่าเริ่มต้นตาม DraconDex)
